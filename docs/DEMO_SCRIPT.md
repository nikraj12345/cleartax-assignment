# Demo script (CEO week)

1. **FAQ** — Chat: “When is the next class?” → schedule + citation  
2. **Video** — “Video not playing on my Android phone” → playbook steps  
3. **Payment** — “Payment failed but money deducted” → reversal guidance + pending txn status  
4. **Refund** — “I need a refund” → pending approval → Finance page → Approve → processed  
5. **Login** — “Forgot my password” → reset initiated notification  

Finance rule: refunds never auto-execute without approver action on `/admin/refunds`.
